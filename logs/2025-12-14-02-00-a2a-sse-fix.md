## Problem

Kagent Web UI was showing error:
```
Streaming failed: A2A proxy request failed: 500 Internal Server Error
server did not respond with Content-Type 'text/event-stream', got application/json
```

The Web UI uses A2A protocol's `StreamMessage` JSON-RPC method for streaming, but the default A2A implementation returns `application/json` instead of `text/event-stream`.

## Root Cause

- Kagent Web UI routes agent requests through A2A proxy
- A2A protocol's `StreamMessage` endpoint returns JSON-RPC responses with `application/json` content type
- Web UI expects SSE format with `text/event-stream` content type for streaming visualization
- The `/run_sse` custom endpoint was not being used by the Web UI routing logic

## Solution Implemented

Added SSE middleware to intercept A2A JSON-RPC streaming requests and convert them to SSE format:

1. **SSEStreamingMiddleware**: Intercepts POST requests to `/` (JSON-RPC endpoint)
2. **Method Detection**: Checks if `method` contains "stream" (case-insensitive)
3. **SSE Conversion**: Returns `StreamingResponse` with `media_type="text/event-stream"`
4. **Pass-through**: Non-streaming requests pass through to default A2A handlers

## Technical Details

### Middleware Implementation
```python
class SSEStreamingMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        if request.method == "POST" and request.url.path == "/":
            body = json.loads(await request.body())
            method = body.get("method", "")
            
            if method and "stream" in method.lower():
                # Extract A2A params
                params = body.get("params", {})
                message_dict = params.get("message", {})
                parts = message_dict.get("parts", [])
                
                # Convert to ADK format and stream with SSE
                return StreamingResponse(
                    event_generator(),
                    media_type="text/event-stream",
                    headers={
                        "Cache-Control": "no-cache",
                        "X-Accel-Buffering": "no",
                    }
                )
        
        return await call_next(request)
```
